# end-to-end project

## Цели и задачи

Оценка стоимости недвижимости в Москве по доступным параметрам:
1) Адрес
2) Площадь
3) Расстояние до метро
4) Этаж
5) Назначение объекта (торговое, офисное помещение)

## Результат

Создан телеграм-бот для предсказания цены
Для модели использовался CatBoostRegressor
